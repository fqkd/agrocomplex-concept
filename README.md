# «Агрокомплекс Выселковский» — инициативная концепция приложения

Работающий веб-прототип собственного канала для регулярных продуктовых покупок: выбор среди 783 точек официального локатора на интерактивной карте OpenStreetMap, актуальный контекст каталога, повтор корзины, замены отсутствующих позиций, список для похода в магазин и программа лояльности. В `/case/` находится отдельная коммерческая презентация.

Это инициативная концепция ООО «ЭРГОХАВЭН», созданная на основе открытых данных. Она не является официальным продуктом АО фирмы «Агрокомплекс» им. Н. И. Ткачёва. Товары, цены, остатки, адрес и статусы в прототипе — демонстрационные; действия не отправляют настоящий заказ и не проводят оплату.

## Маршруты

- `/` — интерактивный прототип. Состояния открываются через hash-маршруты, например `#catalog`, `#product:milk`, `#cart`, `#substitution`, `#checkout`, `#payment-error`, `#success`, `#repeat`, `#shopping-list`, `#loyalty`.
- `/case/` — адаптивная презентация-кейс из 11 разделов.

Hash-маршрутизация сохраняет прямые ссылки и не требует серверного fallback, поэтому обновление страницы на GitHub Pages не приводит к 404. Состояние демосессии сохраняется в `localStorage`.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки и сборка

```bash
npm run lint
npm test
npm run build
npm run preview
npm run qa
```

Production build создаётся в `dist/`. Публикация настроена отдельным GitHub Actions workflow на GitHub Pages из ветки `main`.

Актуальный снимок официального локатора обновляется командой `npm run refresh:stores`; скрипт получает адреса, координаты и часы работы напрямую из JSON-эндпоинта компании.

`npm run qa` запускает production preview, проверяет все состояния прототипа на 360, 390 и 430 px, презентацию на 390, 768 и 1440 px, прямые ссылки, контакты, переполнение и консоль. Браузерный сценарий проходит выбор контекста, отсутствующий товар, замену, ошибку оплаты, возврат с сохранённым состоянием и успешное восстановление.

Исследовательская база и даты проверки приведены в [SOURCES.md](./SOURCES.md).
